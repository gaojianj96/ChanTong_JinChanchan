## 1. 需求摘要 (Phase 0)

**目标**: 在视觉识别(R5)之上建立对局决策中枢: 状态机建模 → 全局牌库概率 → 战术建议(阵容推荐 + D牌/3星决策 + 经济节奏)。**核心用户价值 = "现在该走什么阵容、这个等级值不值得硬 D 三星"。**

**边界**: 纯逻辑引擎优先、接口化输入(stub 先行,R5 真数据后接);不阻塞 C 系列收尾;不涉及自动操作。

## 2.1 M4 架构定案(2026-09-12 用户+Planner)

- **决策核心 = 纯算法**(确定性、可测、<1ms、零成本、可回溯证据);
- **LLM 只做外围**: (a) 关键节点全局参谋(海克斯/出局释放牌库/转阵);(b) 自然语言解释与用户问答;(c) 手动按钮请求;
- 参谋输出与算法建议**并列展示**、都过证据置信层,LLM 不直接改决策;
- 委员会采纳项: E5 拆解(场景接口/规则引擎/解释置信)、证据置信层、golden case 反例矩阵、一期聚焦(阵容+硬D3星+经济),装备/海克斯/锁牌/转阵二期。
