# R 系列计划(定稿): 全量对局存盘与赛后复盘 (Match Archive & Retrospective)

> Planner ｜ 2026-09-12 ｜ 委员会三票(DS 全量 + MiniMax 架构 + Qwen 风险)已综合

## 1. 设计原则(定稿)

- **事件溯源**: append-only 原子事件(seq/ts/schema 版本/可见信息边界/游戏版本/RNG seed);旁路落盘零侵入热路径;
- **WAL 化**: async batch + ring buffer,flush 阈值 100ms/64KB;关键事件同步 fsync;断点续写 + seq 幂等检测;反压时降采样快照、绝不丢事件;
- **分片与索引**: 按 game_id 分片(≤10MB),片头 min/max seq + 类型/decision_id 索引;compaction 归档;
- **存储分层契约**: `meta.json`(全局元数据)→ `event_log/<game_id>.jsonl*`(事件)→ `dataset_index.json`(数据产物)→ `replay/summary`;保留策略 50 局全量 + 长期摘要+关键帧,原始压缩归档;隐私最小字段+开关+TTL;
- **复盘三层判定**: 事实结果 / 决策期望 / 执行质量 分离,标注运气与对手强度,不唯结果;LLM 只做证据引用式解说(禁无据断言),成本熔断。
