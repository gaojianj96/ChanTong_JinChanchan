## 附录(详细玩法说明, 供落库笔记)

### 献祭流沙皇
- 思路来源: B站小古云顶之弈
- 前置: 3莲华开局 + 螳螂早来 + 散件多大棒
- 献祭谁: 献祭 2/3 星螳螂; 螳螂进化: 裁决
- 玩法: 3莲华混搭洛+任意重装开局, 螳螂单挂进化裁决, 7级追3沙皇/蔚/螳螂, 芸阿娜先带婕拉功能装, 上8拆过去; 7级蔚不3但先2星瑟提则瑟提先带肉装; 9级补凯南4裁决或补黑荆棘拉克丝
- 沙皇装备: 能献祭3星螳螂→科技枪(爆发不需要羊刀)+法爆补暴击; 螳螂不3→羊刀合理, 最终优化给婕拉

### 等待/天胡小蓝
- 刚需开局2星小蓝 + 装备偏水滴大棒
- 有"等待得值"则 2-2/2阶段内就D; 妖姬提莫2选1或挂3野怪; 双复制器直接捏3; 然后升人口找5神谕; 4星后一回合发4张, 重复上34星实现指数增长
- 无"等待得值"则2阶不D等3-1抽到3, 最终补大树艾翁; 神谕转给拉露恩换提莫, 宝石换皎月
