## Ⓒ 架构一致性结论：**自洽，未破坏分层**

- **PostProcessor / Anchor / FramePool**：三者均为**横切关注点**而非层级穿透——PostProcessor 属"推理后"层、Anchor 属"几何/校准"层、FramePool 属"运行时/I/O"层，落在既有分层边界内，**未越界**；
- **探针（Probe）**：作为 AOP 式观测，与业务流解耦，可接受；
- **DI 生命周期 × --vision-dry-run**：dry-run 走同一容器同一生命周期，仅禁用 I/O 副作用与权重加载，**生命周期自洽**；建议在 receipt 阶段补一条"dry-run 与实跑路径等价性"的契约测试，防止未来重构漂移。

## Qwen 3.8 Flash (风险预判)

结论：**有条件放行**进入实机验收/权重 receipt；**不放行**默认启用或生产合流。  
代码门禁、双盲评审、dry-run 与几何 Schema 已足以进入真实证据阶段，但当前仍缺权重与实机 receipt，不能证明系统可稳定运行。

风险清单（分级）：

- **P0 阻断**：  
  1. `paddleocr.onnx` 权重来源、hash、许可证、输入输出契约未 receipt；  
  2. 实机延迟/内存/设备回退未达 go/no-go；  
  3. 识别准确率、召回、≥30帧 Golden 人工复核未通过；  
  4. 多 DP I 回归失败。

- **P1 高风险**：  
  1. A3 几何 +3px 偏差未闭环，可能污染 anchor/NMS/ROI 决策；  
  2. DirectML 与 CPU 回退数值/行为差异；  
  3. NMS/Conf/Roi 参数仅在 mock 或单一设备调优；  
  4. OCR 字典纠错误纠或漏纠；  
  5. IFramePool/FrameDropped 背压在真实相机下丢帧策略失效。

- **P2 观察项**：  
  1. 探针覆盖不足；  
  2. 文档复现路径不完整；  
  3. 权重缺失期接口漂移。

下一步放行条件：提交权重 receipt（hash/来源/契约）、实机 go/no-go 报告、识别准确率报告、≥30帧 Golden 复核、多 DP I 回归结果、A3 偏差闭环或明确降级策略。

权重缺失期防腐坏：保持真实推理默认关闭；仅通过 `--vision-dry-run` / stub 契约测试；禁止硬编码权重路径；接口冻结；未 receipt 不得启用默认视觉链路。
