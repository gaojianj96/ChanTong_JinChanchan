# M4 决策引擎立项研讨 Live

## DeepSeek V4.1 Flash (需求)

① **E5覆盖核对**：仅部分覆盖。E5“阵容推荐+D牌决策+经济节奏”可覆盖：阵容选择、D牌、利息、升人口。**未明确覆盖/遗漏**：转阵（触发条件、过渡阵容、保留牌）、3星可行性（期望成本、停手阈值、替代方案）、锁牌/卖牌、装备合成与分配、海克斯/强化选择、同行与血量容错、风险偏好、解释与置信度。E1有3星成本，但E5必须显式消费并输出“值不值得硬D”的决策与理由。

② **3个最大风险**：
1. **需求遗漏导致E5返工**：转阵、锁牌、装备等未入验收，集成后才暴露。
2. **数学/时序错误**：同行扣减、5槽无放回、切屏去重、不可变快照时序若错，推荐不可信。
3. **<1ms与知识库维护冲突**：JSON阵容/装备版本膨胀，性能达标但可解释性、可维护性差。

③ **DAG/拆分/验收建议**：
- E4提前与E1并行，先定JSON schema与最小阵容，避免E5阻塞。
- E5拆为：E5a决策场景接口+特征；E5b规则/概率引擎；E5c解释与置信度。E3可后置，E5先用stub对手。
- 验收建“决策场景矩阵”golden cases：阵容/转阵/D牌/3星/锁牌/利息/升人口/装备各至少1例；超几何对蒙特卡洛；同行扣减时序；快照回放；p99<1ms；JSON schema校验。E6端到端回放验收。
