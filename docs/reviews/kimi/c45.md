# C4.5 Review - Moonshot Kimi K3

**结论：通过（建议合并）**。实现正确、确定性强、测试覆盖核心路径；仅有轻微健壮性与性能改进空间，无阻塞问题。

**Critical**：无。

**Major**：无。

**Minor**
1. **选项未校验**：`MaxDetections<0` 时 `GetRange` 抛 `ArgumentOutOfRangeException`；`NmsThreshold`/`ConfidenceThreshold` 未限制在 `[0,1]`。建议在 `PostProcessOptions` 或入口显式校验并抛 `ArgumentOutOfRangeException`。
2. **ROI 语义未文档化**：当前用检测框中心点判定，且右/下边界为排他（`>=` 排除）。建议在 XML 注释明确“中心点在内、右下开区间”，避免调用方误解。
3. **复杂度**：NMS 为 O(n²)，大候选集（>5k）可能成瓶颈。可后续按 ClassId 分桶或引入软 NMS/坐标排序优化，当前规模可接受。

**Nit**
1. `ComputeIoU` 中 `interArea == 0` 判断可合并到 `interW <= 0 || interH <= 0` 提前返回，减少一次乘法。
2. 测试可补一条 `MaxDetections = 0` 或负数显式抛异常的用例，锁定边界行为。
