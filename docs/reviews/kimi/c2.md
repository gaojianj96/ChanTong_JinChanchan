# C2 Review - Moonshot Kimi K3

## 结论:Pass-with-Notes

数学正确性核验通过:逐轴一元回归即 4 参仿射的最小二乘闭式解,L∞ 重投影误差判定、退化容错(单轴退化亦覆盖)、空帧/比例回退均符合契约;所附 6 测试与实现自洽,手算数值无误。DPI 无关论证成立(物理像素);多显/非独占委托 B3 合理,但本层无实证。231×3 未独立复跑,按证据采信。

### P1(合并前)
1. **Confidence 语义倒挂**:锚点路径 maxErr=2.0(判 Invalid 临界)时 Confidence≈0.8,高于回退 Valid 的 0.5;而回退路径 Invalid 即置 0。下游若按 Confidence 门控,"无效高置信"会压倒"有效回退"。建议 Invalid 时置 0,或文档强制"先判 IsValid"。

### P2(本阶段内)
2. **锚点路径与帧零交叉校验**:自洽但错误的锚点(如拟合出 scale=100×、观测点全部出界)仍判 Valid 且高置信。建议加 |拟合 scale − W/Canonical| 相对偏差或观测点界内检查,超差降置信/判 Invalid。
3. **退化判据为绝对 ε(1e-9)**,未随 canonical 量纲缩放;近退化(病态但 denom≠0)在噪声下产生不稳定解。建议相对阈值,如 denom < ε·n·Σx²。
4. **阶段门槛缺口**:多显/负原点、混合 DPI 在本层无回归。建议补负 Offset 锚点单测(最小二乘本身支持负坐标,成本极低),并与 B3 做一次端到端联测,坐实 ≤2px 委托链。

### P3(择机)
5. 测试缺口:1–3 对锚点回退、自定义 Canonical/阈值、CancellationToken、NaN 输入、null frame;HighError 仅断言 IsValid,未断言 maxErr/Confidence。
6. 细节:异常路径 MaxReprojectionErrorPx=NaN 与回退路径 0.0 不一致;`AnchorPoints` 实为 Observed,命名/注释宜注明;`MaxReprojectionErrorPx=0` 时置信度除零(Clamp 兜底,仍建议校验 options);`MapCanonical` 在 Invalid 结果上静默返回 (0,0),宜注释警示。
