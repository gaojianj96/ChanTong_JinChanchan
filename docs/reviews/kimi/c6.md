# Review: C6 GameSeasonDictionaryTests

**Verdict: Approve.** No blockers. Core paths (exact, fuzzy accept, unknown reject, Levenshtein oracle pairs, numeric parse, set population) are covered and 269/269 ×3 green indicates stability. Gaps below are boundary/completeness items, not correctness risks. Deferral of `RecognizeTextFromRegion` pending weights is correct — but see M4.

## Major (non-blocking, fix soon)

1. **No boundary rejection test.** One-insertion proves accept at distance 1; nothing proves distance = max+1 returns null (e.g., `hero + "xy"`, max 1). The reject side of the threshold is the actual contract.
2. **`ZeroDistance_OnlyExact` is half a test.** It asserts exact passes at max 0 but never asserts a distance-1 near-miss returns null — despite the name promising "OnlyExact."
3. **Only insertion-at-end exercised.** Substitution and deletion consume the same distance budget and are untested; OCR substitution errors are the most common real failure mode.
4. **Tie-breaking unspecified.** Two entries at equal distance: result must be deterministic and pinned by test, or fuzzy match is order-dependent in production.

## Minor

5. **Case/whitespace behavior unpinned.** OCR output will drift in casing; decide whether matching is case-insensitive and lock it in a test.
6. **`TryParseNumeric` too happy-path.** Add null, `" 35"`, `"035"`, `"3.5"`, `"35g"`, and overflow. OCR noise makes malformed digits the norm, not the exception.
7. **Set tests are shallow.** Add: no null/blank entries, distinctness (duplicates make fuzzy results ambiguous), and a count floor to catch accidental data loss on set rotation.
8. **Fuzzy matching only tested against Heroes.** Add one Items case with punctuation/apostrophes — exactly what OCR mangles worst.

## Nits

9. `Heroes.First()` couples to enumeration order; a named constant reads better.
10. Levenshtein: add `("", "") → 0` and one symmetry assertion. Cheap.
11. **Seam hygiene:** file a tracking ticket for real-frame OCR receipt; add a `Skip`-marked golden-image test plus weight-free contract tests (null bitmap, empty region) so the seam can't rot silently while weights are absent.

Solid dictionary-layer work; items 1–4 should land before this is called done.
