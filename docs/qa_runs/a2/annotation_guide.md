# A2 Golden Dataset 标注指南（用户操作手册）

> Planner 准备 ｜ 2026-09-12 ｜ 前置: A1 门禁已通过
> 标注对象: 候选帧 CSV（docs/qa_runs/a2/candidates_core.csv，25 帧核心集；后续可扩至 60+）

## 1. 你需要做什么

对每张帧在**原分辨率(3840x2088)**下标注三个目标集合的中心点(像素坐标):

| 目标 | 数量 | 说明 |
|---|---|---|
| board | 28 | 4 行 x 7 列六角棋盘格的格子中心(棋子站立点,非棋子头像) |
| bench | 9 | 己方备战席格子中心(左到右 1-9) |
| shop | 5 | 底部商店五个卡槽中心 |

- 编号规则: board 用 `row 0-3`(从上到下: 0=近敌阵前? 视屏幕实际)+ `col 0-6`(左到右); bench 0-8 左到右; shop 0-4 左到右。
- **只标能可靠看清的**,看不清的标 `null` 并在 note 写原因。
- 六角棋盘有透视与交错: 每行交错约半个格子宽; 标格子中心(棋子脚下),不是格子外接矩形中心。

## 2. 输出格式(一帧一个 JSON 文件或追加一个数组,按帧)

```json
{
  "src": "F:\\...\\auto_00001358_20260912090949862.jpg",
  "resolution": [3840, 2088],
  "board": [ {"r":0,"c":0,"x":1234,"y":567}, {"r":0,"c":1,"x":1300,"y":560}, ... 28 个或 null 项 ],
  "bench": [ {"i":0,"x":...}, ... 9 个 ],
  "shop": [ {"i":0,"x":...}, ... 5 个(仅画面有商店时) ],
  "note": "可选: 帧内备注(如'选秀界面无商店')"
}
```

存放路径: `docs/qa_runs/a2/annotations/{batch}_{idx}.json`(batch=core/extra)

## 3. 建议流程

1. 先用 3-5 张练手(任意帧),把编号规则固定下来;
2. 核心集 25 帧完成 → 视觉核验员复核(我用 vision 模型对照抽查你的点是否落在格子中心);
3. 复核通过 → 追加 Phase-2 额外帧(board-only 28 点,单帧工作量减半);
4. 全部入库标注 JSON → 进入 A3(切片叠加验证)。
